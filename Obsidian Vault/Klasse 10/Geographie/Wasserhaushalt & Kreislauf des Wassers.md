# Verteilung der Wassermenge
Die Erde besitzt etwa 1,4 Mrd. $km^3$ freies, also verfügbares Wasser. Trotz dieser riesigen Menge ein kostbares Gut,
- weil 97% Salzwasser und damit nur eingeschränkt nutzbar sind.
- Nur 3% sind Süßwasser.
**Verteilung der Süßwasserreserve**
- Süßwasser 2,6%
   - Atmosphäre 0,001%
   - Seen und Flüsse 0,02 %
   - Grundwasser, Bodenfeuchtigkeit 0,58 %
   - Polareis, Meereis, Gletschereis 2,01 %
- Weltmeere (Salzwasser) 97,39 %

Wasser befindet sich im Ständigen Kreislauf von:
- fest
- flüssig
- gasförmig
Es kommt in allen Aggregatzuständen vor.

3 Schritte:
- Verdunstung
- Niederschlag
- Abfluss

# Waserhaushaltsgleichung
Meer $_M$
Land $_L$

$V_M = N_M + A_L$
$N_L = V_L + A_L \rightarrow A_L = N_L - V_L$
$V_M = N_M + N_L - V_L$
$V_L = N_L$
$V_M = N_L$
$V = N$

Regionale Unterschiede
- humider Wasserhaushalt (N>V, viele Flüsse, Seen, Sickerwasser)
- arider Wasserhaushalt (V>N, Salzseen, Endseen, periodisch fließende Flüsse, Salzkrustenbildung)
- nivaler Wasserhaushalt (Unterform humid, Speicherung von Wasser als Rücklage N $\rightarrow$ R, Gletscher, Polareis)

Mischformen (teil des Jahres humid, teil arid)
- semihumid (mehr humid als arid)
- semiarid (mehr arid als humid)
# Mäanderbildung
Wo bilden sich Mäander und warum?
Durch fortsetzende Seitenerosion und Ablagerung von Flusssedimenten entstehen breite Täler (Sohlentäler) überwiegend im Mittellauf

![[Drawing 2026-01-30 08.06.25.excalidraw]]
Prallhang = hohe Fließgeschwindigkeit $\to$ Abtragung durch Seitenerosion, steiles Ufer
Gleithang = geringe Fließgeschwindigkeit $\to$ Ablagerung, flacheres Ufer

kontinuierliche Bewegung des Mäanders in Richtung Prallhang[^1]
wenn zwei Mäander sich treffen, Flusslauf wieder gerade
Entstehung Altwasserarm, Umlaufberg

Deltamündung (fächerförmig): Wolga, Donau, Rhone, Nil
Trichtermündung: Garonne, Elbe, Loire

[^1]: Überschwemmungsgebiet bei Mäandern = Flussaue
## Flussbegradigung (am Rhein)
- um den Fluss schiffbar zu machen
- um Land zu gewinnen
- Deiche sollen Überschwemmung bannen

**Das Tulla-Projekt**
Anfang 19. Jh
Kürzung des Rheins um 80 km
Durchstiche und Dämme machten den Flusslauf gerade
Bau von Deichen

| Maßnahmen                                             | Folgen                                  |
| ----------------------------------------------------- | --------------------------------------- |
| Begradigung                                           | erhöhte Fließgeschwindigkeit            |
| Verstärkung der Form des Flussbetts (Randbefestigung) | starke Erosion an Flussufern            |
| Bau von Dämmen                                        | tieferes Einschneiden in die Landschaft |
| Rückbau der Auewälder                                 | Absenkung des Flussbetts                |
| Abschneiden der Nebenarme                             | Grundwasserabsenkung                    |
| Vertiefung des Flussbetts                             | zunehmende Tiefenerosion                |
| **Ende der Überschwemmungen**                         | **stärkere Hochwasser**                 |

- schnellerer Anstieg der Wasserpegel bei Hochwasser
- Überflutungen der Deiche $\to$ Deichbrüche
- größere Schäden, da natürliche Überflutungsgebiete bebaut sind
  $\implies$Zerstörung von Häusern, Unterspülung von Verkehrswegen, Zerstörung von Ackerflächen, Gefahr für Menschen & Tiere

Zum Schutz vor Hochwasserkatastrophen werden Maßnahmen zur Renaturierung durchgeführt
Renaturierung = Rückführung von Kulturlandschaften (z.B. begradigte Flüsse, Bergbaugebiete)
in einen naturnahen Zustand, mit der Möglichkeit, sich ungestört weiterzuentwickeln, da der Einfluss des Menschen stark eingeschränkt wird

| Ziele                            | Maßnahmen                             |
| -------------------------------- | ------------------------------------- |
| Hochwasserschutz                 | Rückbau Befestigungen                 |
| Lebensraum für Kleinfische       | Bau von Buchten                       |
| Raum für Erholung / Freizeit     | Einbringen von Störsteinen            |
| Ausgleich von anderen Baustellen | künstlich angelegte Seitenarme        |
| Umweltschutz                     | Rückbau von Uferbebauung              |
|                                  | Gewässer zugänglich machen für Fische |
