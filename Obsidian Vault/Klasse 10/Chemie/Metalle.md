# Reaktion von Metallen mit Metallsalzlösungen

|                  | $Zn$ | $Cu$ | $Pb$ |
| ---------------- | ---- | ---- | ---- |
| $ZnSO_{4}$       |      |      |      |
| $CuSO_{4}$       |      |      |      |
| $Pb(NO_{3})_{2}$ |      |      |      |
$\ce{Zn + Pb(NO3)2 -> Pb\downarrow + Zn(NO3)2}$
$\ce{Zn + CuSO4->Cu\downarrow + ZnSO4}$
$\ce{Pb + CuSO4-> Cu\downarrow + PbSO4}$

$\ce{Ca + Pb(NO3)2->Ca(NO3)2 +Pb}$
$\ce{Ca + Pb^{2+} + 2NO3- -> Ca^{2+} + 2NO3- + Pb}$
$\ce{2 Cr + 3NiSO4->Cr2(SO4)3+ 3Ni}$
$\ce{2Cr + 2Ni^{2+} + 3SO4^{2-} -> 2Cr^{3+} + 3SO4^{2-} + 3Ni}$
$\ce{Co + ZnSO4 \not\rightarrow}$

Reduktionsmittel
$Zn>Pb>Cu$
Oxidationsmittel
$Zn^{2+}<Pb^{2+}<Cu^{2+}$
(komplette Tabelle: $\nearrow$Tafelwerk S.122)

Wasserstoff teilt die Tabelle
- alles über $H_{2}$: durch nichtoxidierende Säuren löslich
- alles unter $H_{2}$: **nicht** durch nichtoxidierende Säuren löslich

unter $H_{2}$ kann auch durch oxidierende Säuren gelöst werden:
- konzentrierte Salpetersäure ($\ce{Ag + 2HNO3<=>AgNO3+ + NO2\uparrow+ H2O}$)
- Königswasser
