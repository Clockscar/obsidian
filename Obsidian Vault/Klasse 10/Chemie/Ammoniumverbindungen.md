# Reaktionen
Nachweis von $\ce{NH4+}$
im Uhrglas mit angefeuchtetem Unitest-Papier (kreuzförmig innen-außen), ca. 1,5 ml verd. Natronlauge hinzugeben $\rightarrow$ Verfärbung zu blau (innerer schneller als äußerer)
$\ce{NaOH + NH4Cl -> NH3\uparrow + H2O + NaCl}$
$\ce{Na+ + OH- + NH4+ +Cl- -> NH3\uparrow + H2O + Na+ +Cl-}$
Säure-Base-R.
1. korr. S-B
	$\ce{NH4+ <=> H+ + NH3}$
	 $S_1$                      $B_1$ 
2. korr. S-B
	$\ce{OH- +H+ <=> H2O}$
	 $B_2$                     $S_2$ 
$\ce{NH4+ +OH- <=> NH3 + H2O}$
$\ce{S1 + B2   <=> B1 +S2}$

$\ce{NH3 + H2O <=> NH+ + OH-}$
Überschuss an $OH^-$ als Färbung am Unitest erkennbar
Säure-Base-R.
1. korr. S-B
	$\ce{H2O <=> H+ + OH-}$
	 $S_1$                     $B_1$
2. korr. S-B
	$\ce{NH3 + H2O <=> NH4+ + OH-}$
	 $B_2$                                   $S_2$  
$\ce{NH3 + H2O <=> NH4+ ü OH-}$
$\ce{B2 + S1 <=> S2 + B1}$

# Thermische Zersetzung
Ammoniumchlorid:
	$\ce{NH4Cl -> NH3 + HCl}$
Ammoniumcarbonat:
	$\ce{(NH4)2CO3 -> 2NH3_{(g)} + H2O_{(g)} +CO2_{(g)}}$
Ammoniumnitrat:
	$\ce{NH4NO3 -> NO2_{(g)} + 2H2O_{(g)}}$
	$\ce{2NH4NO3 -> 2N2_{(g)} + O2_{(g)} + 4H2O_{(g)}}$
Ammoniumnitrit:
	$\ce{NH4NO2 -> N2 +2H2O}$

# Bildung von Ammoniumverbindungen:
- durch Einleiten von Ammoniak ($NH_4$) in die entsprechenden Säuren:
	$\ce{HCl + NH3 -> NH4Cl}$
	$\ce{H3O+ Cl- + NH3 -> NH4+ + Cl- +H2O}$

	$\ce{H2SO4 + NH3 -> (NH4)2SO4}$
	$\ce{2H3O+ +SO4^{2-} NH3 -> 2NH4+ + SO4^{2-} +2H2O}$

	$\ce{H2CO3 + NH3 -> NH4HCO3}$
	$\ce{H3O+ + HCO3- + NH3 -> NH4+ + HCO3- + H2O}$

Beseitigung von Warzen: $\ce{AgNO3}$ (Höllsteinstift)
