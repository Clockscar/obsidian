- Horizont = gedachte Kreislinie auf der scheinbaren Himmelskugel, die das Sichtbare vom Unsichtbaren trennt
- scheinbare Himmelskugel = gedachte Kugel um den Beobachter, kein  definierter Radius
- Zenit = Punkt über dem Beobachter
- Himmelsnordpol = projizierter Punkt auf scheinbare Himmelskugel von Erdachse
- Himmelsäquator = projizierter Erdäquator auf Himmelskugel
- Sternbild = eine Gruppe von Sternen, die aus unserer Sicht ein Bild ergeben (haben verschiedene Farbe / Form / Entfernung / Größe)
# Horizont - System
![[Drawing 2025-12-15 14.19.26.excalidraw]]
$\color{green}a$  Azimut
im Gradmaß angegebene Himmelsrichtung
- $a=0°$ Süden
- $a=90°$ Westen
- $a=180°$ Norden
- $a=270°$ Osten
- $0°\leq a \leq 360°$

$\color{lightblue}h$  Höhe
im Gradmaß angegebener Abstand zum Horizont
- $h=0°$ Horizont
- $h=90°$ Zenit
- $0°\leq h \leq 90°$

# Äquator - System
Horizontsystem zwar praktisch, aber orts- und zeitabhängig

**Koordinaten**
$\alpha$  Rektaszension (lat. gerade Aufsteigen)
Projektion der Längengrade der Erde auf die scheinbare Himmelskugel
- Nullmeridian geht durch den Frühlingspunkt (Widderpunkt, Schnittpunkt Ekliptik Himmelsäquator)
- gemessen  in $[1^h]$ Stunden
- $0^h\leq \alpha \leq 24^h$

$\delta$  Deklination
Projektion der Breitengrade der Erde auf die scheinbare Himmelskugel
- Nullmeridian ist der Himmelsäquator
- gemessen in $[1°]$ Grad
- $-90° \leq \delta \leq 90°$
